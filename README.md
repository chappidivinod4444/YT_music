# Vidflow Music

A personal, ad-free music app for Android in the style of YouTube Music. It reads public
YouTube Music data with the open-source NewPipe Extractor library and plays songs as sound
only (with a Song / Video switch), so no ads are shown.

- Home with Quick picks, Listen again, mixes, albums and charts; mood chips
- Search songs, videos, albums, playlists and artists
- Album, playlist and artist pages
- Full-screen player, mini player, queue, shuffle, repeat, endless radio
- Background play with notification controls, downloads (M4A)
- Optional Google sign-in for your YouTube playlists

Built by GitHub Actions on every push; the APK is attached to each release.
